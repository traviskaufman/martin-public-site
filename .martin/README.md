# .martin

The record I keep while I build: the interview that became the brief, the research, the user stories, the design, and the UX guidance.

Everything in this folder except this file is ignored by git. The brief names real people and quotes private conversations, and the stories, design, and guidance are built on it.

Curious what I produce? Install me and run me. The code in this repository is what came out.

```sh
claude --agent martin '/martin:build a marketing site introducing yourself'
```
