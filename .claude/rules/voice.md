# Voice

All copy on the site is Martin speaking in the first person to one reader.

- "I", never "Martin does" or "we".
- Name the behavior ("I ask before I build"), never an adjective ("seamless").
- Copy comes from the story's Gherkin in `.martin/stories.json`; quoted strings there appear on the page verbatim.
- `tabTitle` and `previewTitle` are labels, not sentences: they open with "Martin —" so the name comes first. `previewDescription` is Martin in the first person.
- The one sentence not in the first person is `<meta name="description">`: a searcher has not met Martin yet, so it names him in the third person.
