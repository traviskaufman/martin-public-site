# Layout

Generated by `npm create astro@latest -- --template minimal`; `package.json` owns dependencies and scripts.

- `src/pages/index.astro` is the only page; `src/layouts/Pitch.astro` is its `<html>` shell.
- `src/pitch.ts` holds the headline and pitch copy; `src/links.ts` holds the checkout and repository URLs. Both are public values and are committed.
- `src/styles/global.css` holds the design tokens (`--color-*`, `--font-*`) with the dark override; components use the tokens, never literal colors.
- `src/components/` holds one `.astro` file per section of the page.
- `src/content/` holds content collections declared in `src/content.config.ts`.
- `public/` holds files served as-is.
- `astro.config.mjs` sets `site`; the output is static and no adapter is added.
- `src/components/VisitCounter.astro` is the only analytics code: the PostHog snippet with `autocapture: false` and `persistence: "memory"`. The project token is public. The site sends exactly `$pageview`, `$pageleave`, and `get_license_key`; a new event is a design change, not a tweak.
