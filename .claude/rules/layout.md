# Layout

Generated by `npm create astro@latest -- --template minimal`; `package.json` owns dependencies and scripts.

- `src/pages/index.astro` is the only page.
- `src/components/` holds one `.astro` file per section of the page.
- `src/content/` holds content collections declared in `src/content.config.ts`.
- `public/` holds files served as-is.
- `astro.config.mjs` sets `site`; the output is static and no adapter is added.
