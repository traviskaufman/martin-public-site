# Layout

Generated by `npm create astro@latest -- --template minimal`; `package.json` owns dependencies and scripts.

- `src/pages/index.astro` is the only page; `src/layouts/Pitch.astro` is its `<html>` shell, holding the head (with the inline theme guard), the footer, and the top bar after the footer so the hero's license-key button stays first in document order.
- `src/pitch.ts` holds the headline and pitch copy; `src/links.ts` holds the checkout and repository URLs. Both are public values and are committed.
- `src/styles/global.css` holds the design tokens (`--color-*`, `--radius-*`, `--font-*`): Solarized dark on `:root` for everyone regardless of system theme, light on `:root[data-theme="light"]` once the visitor chooses it. Components use the tokens, never literal colors. `src/styles/terminal.css` holds the terminal chrome and pane, imported by `Terminal` and `ClosingPrompt`.
- `public/fonts/` holds Geist and Geist Mono as Latin-subset variable woff2 files, declared in `global.css` and preloaded from `Pitch.astro`; no third-party font requests.
- `src/components/` holds one `.astro` file per Figma component.
- `src/assets/*.svg` are the site's vectors, one file each, imported as Astro SVG components (`import Sun from "../assets/sun.svg"`) with `class` and `aria-hidden` passed as props; a new icon is a new file there, never `<svg>` markup typed into a component.
- `src/assets/mark.svg` is the logo's mark, Figma's export with `currentColor` fills; never redraw its paths. `Mark` renders it 1em tall in `--color-accent`, and a place that wants another color sets `--mark-color`. `public/favicon.svg` and `public/og.png` are made from the same paths (commands in `AGENTS.md`).
- `src/content/` holds content collections declared in `src/content.config.ts`. `src/content/comparisons/*.yaml` are verbatim transcripts from real sessions; edit them only to swap in a new recording, never to tidy the wording. `src/content/scenes/*.yaml` are what the terminal plays under each section (`section` is the id of the heading it follows); a scene either carries its own `transcript` or references a `comparison`, whose Martin half, prompt, and differentiator it reuses, optionally from a `startAt` line. `src/scenes.ts` resolves them in order.
- `src/comparisons.ts` holds the ordered comparison headings; `index.astro` renders one `ComparisonVanilla` per heading and, in dev only, a placeholder for a heading with no entry. Martin's half of every comparison is the terminal, titled "Martin".
- `src/scripts/` holds the terminal's client code: `terminal-stage.ts` wraps the DOM, `scene-follower.ts` picks the section in the top third of the window, and `playback.ts` types scenes and is imported lazily once the terminal is visible. `<script>` blocks in `.astro` files stay plain JavaScript and import from there.
- `public/` holds files served as-is, including `install.sh` (the one-command installer; its checks all run before its first write, and `tests/installing-with-one-command.spec.ts` runs it against stub `claude` and `curl` commands) and `llms.txt` (the install instructions for agents).
- `astro.config.mjs` sets `site`; the output is static and no adapter is added. `functions/index.ts` is the one Pages Function, deployed beside `dist/`: it answers a request for `/` that asks for `text/markdown` with `llms.txt`, and a new function is a design change, not a tweak.
- `src/components/VisitCounter.astro` is the only analytics code: the PostHog snippet with `autocapture: false` and `persistence: "memory"`. The project token is public. The site sends exactly `$pageview`, `$pageleave`, and `get_license_key`; a new event is a design change, not a tweak. Every "Get your license key for $5" button — hero, top bar, after you pay, closing prompt — is a `LicenseKeyButton`, so all four send that one event.
