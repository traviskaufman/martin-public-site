# Layout

Generated by `npm create astro@latest -- --template minimal`; `package.json` owns dependencies and scripts.

- `src/pages/index.astro` is the pitch and `src/pages/thanks.astro` is the thank-you page Stripe redirects buyers to (`noindex`, no top bar, no license-key button, no analytics). `src/layouts/Site.astro` is the `<html>` shell both share: the head (with the inline theme guard, font preloads, and a `head` slot), `<main>`, the footer, and an `after-footer` slot. `src/layouts/Pitch.astro` builds on it with the pitch's meta tags and `VisitCounter` in `head`, and the top bar in `after-footer` so the hero's license-key button stays first in document order.
- `astro.config.mjs` sets `build.format: "file"`, so `/thanks` is served from `thanks.html` without a redirect to `/thanks/`.
- `src/pitch.ts` holds the headline and pitch copy, plus three lines written separately because they do separate jobs: `tabTitle` (the `<title>`: brand first so it survives a narrow tab, then what Martin is, for a search result), `previewTitle` (`og:title`: must read complete alone, since some apps show no description), and `previewDescription` (`og:description`: the behaviours, never a restatement of the title); `src/links.ts` holds the checkout and repository URLs. Both are public values and are committed.
- `src/styles/global.css` holds the design tokens (`--color-*`, `--radius-*`, `--font-*`): Solarized dark on `:root` for everyone regardless of system theme, light on `:root[data-theme="light"]` once the visitor chooses it. Components use the tokens, never literal colors. `src/styles/terminal.css` holds the terminal chrome and pane, imported by `Terminal` and `ClosingPrompt`.
- `public/fonts/` holds Geist and Geist Mono as Latin-subset variable woff2 files, declared in `global.css` and preloaded from `Site.astro`; no third-party font requests.
- `src/components/` holds one `.astro` file per Figma component.
- `src/assets/*.svg` are the site's vectors, one file each, imported as Astro SVG components (`import Sun from "../assets/sun.svg"`) with `class` and `aria-hidden` passed as props; a new icon is a new file there, never `<svg>` markup typed into a component.
- `src/assets/mark.svg` is the logo's mark, Figma's export with `currentColor` fills; never redraw its paths. `Mark` renders it 1em tall in `--color-accent`, and a place that wants another color sets `--mark-color`. `public/favicon.svg` and `public/og.png` are made from the same paths (commands in `AGENTS.md`).
- `src/content/` holds content collections declared in `src/content.config.ts`. `src/content/comparisons/*.yaml` are verbatim transcripts from real sessions; edit them only to swap in a new recording, never to tidy the wording. `src/content/beats/*.yaml` are what the terminal plays under each section (`section` is the id of the heading it follows); a beat either carries its own `transcript` or references a `comparison`, whose Martin half it reuses, optionally from a `startAt` line. An opening beat has a `title` and a `command`; a beat with `continues: true` has neither and is appended to the session on screen; `inlineOnPhone: false` keeps a beat out of the phone's inline terminals. `src/beats.ts` resolves them in order; `src/session.ts` groups them into sessions. A beat may introduce a recorded excerpt with the tool-call line that produced it.
- `src/sections.ts` holds the three differentiator sections (`id`, `title`, `sentence`, `comparisons`); `index.astro` renders each as a `<section>` with an `<h2>`, the byline, and (on a phone) a `ComparisonTabs` holding an inline `Terminal` and a `ComparisonVanilla`, plus, in dev only, a placeholder when a named comparison has no entry. `TerminalTrack` is the desktop column: one `ComparisonTabs` around the terminal that follows the scroll, with every section's vanilla panel in its second tab and only the current section's shown. Martin's half of every comparison is the terminal.
- `src/scripts/` holds the terminal's client code: `terminal-stage.ts` wraps the DOM, `beat-follower.ts` picks the section in the top third of the window, `playback.ts` types beats and is imported lazily once a terminal is visible, and `comparison-tabs.ts` drives the tab row. The head guard in `Site.astro` sets `data-js` on `<html>` before first paint; `terminal.css` hides a `static` terminal's transcript under it until a script binds, and reveals it after 3s if none does. `<script>` blocks in `.astro` files stay plain JavaScript and import from there.
- `public/` holds files served as-is, including `install.sh` (the one-command installer; its checks all run before its first write, and `tests/installing-with-one-command.spec.ts` runs it against stub `claude` and `curl` commands) and `llms.txt` (the install instructions for agents).
- `astro.config.mjs` sets `site`; the output is static and no adapter is added. `functions/index.ts` is the one Pages Function, deployed beside `dist/`: it answers a request for `/` that asks for `text/markdown` with `llms.txt`, and a new function is a design change, not a tweak.
- `src/components/VisitCounter.astro` is the only analytics code, rendered by `Pitch.astro` only: the PostHog snippet with `autocapture: false` and `persistence: "memory"`. The project token is public. The site sends exactly `$pageview`, `$pageleave`, and `get_license_key`; a new event is a design change, not a tweak. Every "Get your license key for $5" button — hero, top bar, after you pay, closing prompt — is a `LicenseKeyButton`, so all four send that one event.
